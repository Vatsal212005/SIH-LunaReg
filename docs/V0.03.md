
# LunaReg V0.03 Initial - Low-Compute Robustness Harness

V0.03 Initial does not train a model and does not require any new lunar imagery.

It reuses Canonical Pair 001 from V0.01.2 and SuperPoint + LightGlue from V0.02.

## What it tests

Five spatially disjoint native-resolution subpairs are extracted from the existing
1500 x 1500 OHRC/LRO canonical pair:

- northwest
- northeast
- center
- southwest
- southeast

Each crop is 480 x 480 at the existing 1 m/px common map grid. The regions do not
overlap, but they still belong to the same scientific acquisition pair. They therefore
test spatial robustness, not cross-acquisition generalization.

The center crop is also used for three controlled stress cases:

- scale 0.75x
- rotation +10 degrees
- gamma 0.60 with contrast 1.20

The illumination case is a photometric stress proxy. It must not be presented as proof
of real Sun-angle invariance.

## Compute policy

- no training
- no new packages
- no new model weights
- one SuperPoint + LightGlue model session
- model loaded once for the complete suite
- 512 SuperPoint keypoints maximum
- 480 x 480 inputs
- sequential inference only
- existing V0.02 thermal guard before every case
- no LoFTR
- no repeated timing loops

Default full initial suite: 8 learned inferences.

## Run

Full initial suite:


Only five native regions:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\RUN-V0.03.ps1 -Suite regions
```

Only three stress cases:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\RUN-V0.03.ps1 -Suite stress
```

## Diagnostic classes

V0.03 adds an engineering-only robustness label:

- ROBUST: at least 20 verified inliers and at least 0.35 spatial coverage
- PARTIAL: at least 6 verified inliers but below the ROBUST threshold
- FAILED: fewer than 6 verified inliers

These labels are internal experiment diagnostics, not ISRO acceptance thresholds.

## Scientific limitation

V0.03 Initial still uses only one OHRC/LRO acquisition pair. A later stronger V0.03
validation stage should add different OHRC acquisitions before any cross-acquisition
generalization claim is made.
